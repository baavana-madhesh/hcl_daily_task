
# Day 13 - Functional Programming

## Objective
Use Java functional interfaces and lambda expressions to build a product filter.

## Features
- Filter products by price, category, and stock status
- Combine predicates using and()
- Transform product names using Function
- Print results using Consumer
- Create a default product using Supplier
- Use method references

## Concepts Covered
- Lambda expressions
- Predicate
- Function
- Consumer
- Supplier
- Method references
- Functional composition

## Run
```bash
javac FilterEngine.java
java FilterEngine
```
