
# Day 12 - Assessment 1: Core Java Checkpoint

## Objective
Integrate Core Java concepts from Days 1-11 into a console application.

## Features
- Student management using OOP
- Add and display students
- Search students by ID
- Store student records using Collections
- Validate student data
- Handle invalid input and duplicate IDs
- Override toString() for readable output

## Concepts Covered
- Java fundamentals
- Classes and objects
- Encapsulation
- Constructors
- ArrayList and Collections
- Exception handling
- Loops and conditional statements

## Run
```bash
javac CoreJavaAssessment.java
java CoreJavaAssessment
```

## Expected Result
The application displays student records, searches for a student,
and handles duplicate student IDs.
